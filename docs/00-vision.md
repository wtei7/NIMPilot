# Vision

NIMPilot은 NVIDIA NIM과 LiteLLM을 하나의 Docker로 관리하는 AI Gateway이다.

목표는 단순한 LiteLLM 설정 도구가 아니라
AI 모델 자동 관리 플랫폼이다.

핵심 목표

- NVIDIA 모델 자동 탐색
- LiteLLM Config 자동 생성
- Docker 기반 실행
- Dashboard 제공
- 모델 벤치마크
- 모델 추천
- AI Router
- OpenAI Compatible API 제공

최종적으로 사용자는

docker compose up -d

한 번만 실행하면 된다.
